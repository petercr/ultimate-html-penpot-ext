# Penpot Hub submission

## Listing copy

**Plugin title:** Ultimate HTML to Penpot

**Description:** Turn pasted HTML into editable, responsive Penpot boards. Capture desktop, tablet, and mobile layouts in the browser, inspect diagnostics before importing, and keep text, boxes, flex layouts, images, and inline SVG editable.

**Key features and use cases:**

- Convert pasted HTML and CSS into editable Penpot layers.
- Generate desktop, tablet, and mobile boards in one import.
- Preserve responsive layout, text wrapping, images, inline SVG, and common flex layouts.
- Review layer counts and unsupported-content diagnostics before importing.
- Run entirely in the browser with no production backend in v0.1.0.
- Use direct page URLs on a best-effort basis when the target site permits browser CORS.
